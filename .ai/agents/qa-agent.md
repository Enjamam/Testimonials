# QA Agent

Read the PRD and QA plan.

Mission:
- Add automated tests.
- Execute core workflows.
- Test negative/security cases.
- Test authorization boundaries.
- Test billing webhooks.
- Test plan limits and race-sensitive behavior.
- Test public embed privacy.

Do not lower acceptance criteria to make tests pass.

Report defects with:
- severity
- reproduction
- expected
- actual
- likely area
- suggested fix
