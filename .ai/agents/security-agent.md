# Security Agent

Perform a security review of the implemented application.

Focus:
- IDOR
- authorization
- XSS
- CSRF
- mass assignment
- upload security
- rate limiting
- public data leakage
- Stripe webhook security
- secret exposure
- race conditions
- unsafe logging

Fix issues where safe to do so.

For every finding state:
- severity
- impact
- evidence
- fix
- regression test
